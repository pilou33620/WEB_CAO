# WEB_CAO

Un outil de Conception Assistée par Ordinateur (CAO) orienté web pour l'édition de schémas électroniques et de PCB.

## Structure du Projet

- `editeur-schematique/` : Éditeur de schémas électroniques.
- `editeur-pcb/` : Éditeur de circuits imprimés (PCB).
- `index.html` : Point d'entrée principal de l'application.
- Scripts utilitaires pour le traitement de données et d'interfaces.

## Installation / Utilisation

Vous pouvez utiliser le serveur Python fourni pour tester l'application en local :

`ash
